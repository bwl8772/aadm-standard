# Maintainers

This file identifies **community maintainer expectations** and **contact paths** for this public repository.

## Maintainer responsibilities

- Triage issues and pull requests constructively  
- Uphold [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md)  
- Keep content aligned with the repo’s scope: **standard adoption**, not proprietary products  
- Coordinate security reports per [`SECURITY.md`](../SECURITY.md)

## Contact

- **General discussion:** GitHub Issues / Discussions (if enabled)  
- **Security-sensitive reports:** follow [`SECURITY.md`](../SECURITY.md) — do not file publicly
