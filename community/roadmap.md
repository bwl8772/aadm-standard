# Roadmap

This public repository evolves with community needs. Items below are **directional**, not commitments.

## Near term

- Expand examples with additional vertical slices (API-only service, data pipeline sketch)  
- Cross-links diagram pack (optional Mermaid snippets) for layer discussions  
- Translation-friendly wording passes on core docs  

## Mid term

- Maintainer-reviewed FAQ sourced from common adoption questions  
- Optional JSON artifacts for layer maps (tooling-neutral schemas)  

## Principles for changes

- Preserve **separation** between public standard docs and proprietary implementations  
- Prefer **small, reviewable** contributions  
- Avoid embedding **client-specific** or **regulated** content in examples  

## How to propose work

Open an issue describing the gap, proposed artifact, and audience. See [`CONTRIBUTING.md`](../CONTRIBUTING.md).
