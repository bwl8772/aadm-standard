This folder is a **fictional, self-contained example** showing how AADM templates stitch together for a small agent-assisted feature. **No proprietary logic** is included—only narrative artifacts you can copy.

## How to use

1. Read files top-down in the table order.  
2. Replace names, IDs, and domains with your program’s terms.  
3. Delete fictional sections that do not apply.

This example **does not** prescribe a programming language, framework, or vendor MCP implementation.
