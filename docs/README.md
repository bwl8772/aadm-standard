# Documentation index

Start at the [project README](../README.md) for positioning, and at [`../GOVERNANCE.md`](../GOVERNANCE.md) for the standard-governs-implementations charter. **Agents:** you do **not** need the hosted MCP — see [AI coder playbook](ai-coder-playbook.md). The hosted MCP is a convenience; the connection details remain at [www.aadm.io](https://www.aadm.io).

**AADM** here means **Agentic Authority Delivery Model** — open guidance, not a law or formal standards-body publication unless separately claimed by your organization.
